# OLA Ride Bookings Analysis

## 📌 Project Overview
This project analyzes OLA ride booking data to uncover booking trends, customer behavior, ride cancellations, revenue insights, and operational performance using Excel, Google Sheets, SQL, and Power BI.

## 🛠 Tools & Technologies
- Excel
- Google Sheets
- SQL (MySQL)
- Power BI

## 📂 Project Files
- `OLA_Bookings.csv` – Dataset
- `Ola-bookings.sql` – SQL queries
- `Ola-bookings.pbix` – Power BI dashboard
- `Dashboard/` – Dashboard screenshots

## 📊 Dashboard Preview
Dashboard screenshots are available in the **Dashboard** folder.

## 🔍 Key Insights
- Total bookings analysis
- Ride status distribution
- Revenue trends
- Cancellation analysis
- Vehicle type performance
- Customer ratings
- Booking value analysis
